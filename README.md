
# Savor - Restaurant Menu

A responsive restaurant menu application built with React.

## Features
- Browse restaurant dishes
- Search dishes by name
- Filter by food category
- Sort dishes by price
- Add and remove cart items
- Update item quantities
- Save favorite dishes
- Contact form
- Responsive design

## Technologies
- React
- Vite
- React Router
- JavaScript
- CSS
- JSON

## How to Run

1. Clone the repository
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev
